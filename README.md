# Alura Store – Análisis de Ventas y Rendimiento de Tiendas

Este proyecto forma parte del desafío del curso de Ciencia de Datos de Alura Latam. El objetivo es ayudar al Sr. Juan a decidir cuál de sus cuatro tiendas debería vender, con base en un análisis de desempeño.

## Objetivo

Analizar y comparar el rendimiento de **4 tiendas** en cinco aspectos clave:

1. **Facturación total**
2. **Ventas por categoría**
3. **Calificación promedio**
4. **Productos más y menos vendidos**
5. **Costo promedio de envío**

---

## Estructura del Proyecto

- `tienda_1.csv`, `tienda_2.csv`, `tienda_3.csv`, `tienda_4.csv`: Bases de datos con información de ventas por tienda.
- `AluraStoreLatam.ipynb`: Notebook con todo el análisis realizado paso a paso.
- `README.md`: Este documento explicativo.

## Conclusión

Tras el análisis de los cinco aspectos clave, se concluyó que la **Tienda 4** presenta el menor rendimiento general, por lo que se recomienda vender esta tienda para reinvertir en un nuevo negocio.
